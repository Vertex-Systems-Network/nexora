# Nexora Definition of Done

A feature is complete only when applicable items are green:

## Backend
- implementation complete;
- validation complete;
- authorization/policy complete;
- audit/security behavior considered;
- migrations included;
- factory included;
- seeder included if required;
- unit/feature/integration tests included.

## Admin UX
- premium visual hierarchy;
- consistent spacing;
- responsive behavior;
- page/data loading behavior;
- skeleton state;
- button/action loading state;
- empty state;
- error + retry state;
- permissions state;
- light/dark behavior;
- keyboard/focus accessibility;
- no avoidable layout shift;
- destructive action confirmation.

## Quality
- TypeScript strict checks pass;
- PHP checks pass;
- fresh migrations pass;
- fresh migrations + seeds pass;
- production frontend build passes;
- no debug/temporary/dead files;
- documentation updated.
